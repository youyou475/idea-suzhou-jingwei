# 经纬二重 · 苏州织造的数字演化

> 2026 年“IDEA苏州”大学生文化创意设计大赛 · 赛道二「非遗新生 · 数字演化」· 互动类 H5

以苏州缂丝的**通经断纬**与纱罗的**绞经成孔**两项织造技艺为核，将其工序转译为可交互的数字织机。
经线贯通全幅不断，纬线依图稿色区各自回梭，色界处遂留下真实缂丝才有的细缝——这道缝正是行家辨真伪的凭据。
另设苏罗一屏：两根经线周期性互绞，把纬线锁成稳定的椒孔。
二者一在纬上做减法，一在经上做加法，同出苏州织造一脉。

**在线访问**：https://jingwei-erzhong.netlify.app/

## 交互结构（七屏，640 × 1008 px）

| 屏 | 内容 | 交互 |
|---|---|---|
| P1 | 封面 · 一寸缂丝一寸金 | — |

## 技术说明

- **纯前端单文件**：HTML5 + Canvas 2D + 原生 JavaScript，不依赖任何库、字体包或网络资源，离线可运行。
- **图形全部由算法生成**：纹样、色谱、经纬与绞经结构均为手写参数化算法（三角函数与伪随机分布）绘制，
  未使用任何 AI 生成素材、第三方图像资源或外部图片。
- **声音由代码合成**：背景音乐以 Web Audio 实时合成（五声音阶缓行 + 织机投梭声），不使用受版权保护的音乐素材；
  语音讲解默认由设备内置中文语音朗读，也可外接录音文件。
- **移动端适配**：按 640 × 1008 设计稿等比缩放并显式居中，兼容 iOS Safari、Android Chrome 与微信内置浏览器。
  因浏览器禁止无手势自动播放，声音于首次触摸时起播，右上角常驻开关。

## 目录结构

```
index.html              成品单文件，可直接部署或离线打开
src/
  weave-pattern.js      纹样与色谱引擎（四式纹样、六组丝色、切「梭」）
  app.js                交互逻辑、动画调度与声音合成
  app.css               样式
  index.template.html   页面骨架
  build.cjs             合成脚本：把 src 内联进模板，输出单文件 index.html
```

## 构建

```bash
node src/build.cjs
```

脚本会自动判断输出位置：本地工程输出到 `01_H5/index.html`，源码单独抽出时输出到根目录 `index.html`。

## 调试参数

| 参数 | 作用 |
|---|---|
| `#pN` | 直接跳到第 N 屏 |
| `?still=1` | 静态满幅模式（关闭动画，用于取图） |
| `?static=1` | 关闭页面过渡（截图必需，否则画面停在半透明状态） |
| `?frame=N` | 锁定动画进度到第 N 秒，取任意中间帧 |
| `?full=1` | 织造页直接织满 |
| `?export=1\|2\|3` | 导出高清素材（织造成品 / 苏罗绞经 / 通经断纬机制图） |
